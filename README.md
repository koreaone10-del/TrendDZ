# TrendDZ v2 — Android Product Engine

تطبيق خفيف لإدارة منتجات الدروبشيبنغ في الجزائر.

## ما تم بناؤه
- التعرف على Sawa9ly / Baba Algeria / DropDZ / Prix Choc من الرابط.
- استخراج رقم المنتج أو قيمة `?p=` تلقائيًا.
- فتح صفحة المنتج داخل WebView مخفي لاستخراج `og:image` / `twitter:image` / صورة `img` مباشرة من صفحة التسويق.
- حفظ رابط الصورة كما هو، بدل تنزيل الصورة وإعادة رفعها.
- حفظ المنتجات محليًا على الهاتف.
- حساب Trend Score أولي heuristic (ليس بيانات سوق حية بعد).
- تصدير المنتجات كـ `storeData` متوافق مع فكرة `products.js`.
- عدم تخزين كلمات مرور المنصات.

## بناء APK
افتح المشروع في Android Studio ثم Sync/Build APK.

النسخة الحالية تستخدم Android SDK فقط ولا تحتاج مكتبات خارجية داخل التطبيق.

## ملاحظة مهمة
بعض المواقع قد تستخدم Cloudflare أو تسجيل دخول. في هذه الحالة WebView قد يعرض صفحة التحقق بدل المنتج؛ التطبيق لا يتجاوز الحماية. يمكن للمستخدم فتح الصفحة وتسجيل الدخول في المتصفح/الموقع ثم استخدام الرابط، أو لصق رابط الصورة يدويًا إذا منع الموقع استخراجها.

## Provider order modes
- Sawa9ly: PRODUCT_THEN_FORM
- Baba Algeria: PRODUCT_THEN_FORM
- DropDZ: PRODUCT_OR_FORM
- Prix Choc: LANDING_THEN_FORM

## الخطوة التالية المقترحة
إضافة Trend Radar حقيقي يجمع مؤشرات: المشاهدات/التفاعل، سعر المورد، الهامش، سهولة الفيديو، المنافسة، مخاطر الإرجاع، وتاريخ نتائج الاختبارات، ثم يعطي BUY / TEST / KILL.
